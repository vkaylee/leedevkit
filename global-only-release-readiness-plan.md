# Khắc phục blocker release global-only

Status: Approved — implementation in progress

## Mục tiêu và giới hạn

Đưa migration global-only tới trạng thái đủ bằng chứng release; không commit, push, gắn tag hoặc phát hành trong kế hoạch này. Giữ thay đổi sẵn có trong `leedevkit.toml`, dữ liệu project, `leedevkit.lock` và các release cũ. Checksum không xác thực nhà phát hành; không mô tả nó như chữ ký.

Quyết định mới: bỏ điều kiện parity với Python cũ. Mục 2 bên dưới ghi lịch sử; gate hiện báo thành công khi mọi check infra được cấu hình thành công. Các blocker release khác vẫn áp dụng.

## Công việc

1. [ ] **Installer an toàn:** Viết test tái hiện trước, rồi giới hạn streaming download archive, checksum và phản hồi latest; giới hạn byte giải nén, số entry, đường dẫn và loại entry trước khi ghi. Kiểm tra response chunked không có `Content-Length`, archive nén lớn, nhiều entry, hỏng và đường dẫn độc hại; từ chối an toàn và giữ `current`. Không dùng giới hạn chỉ dựa vào header hoặc pipeline nuốt lỗi. Đánh giá dùng chung logic Go chỉ khi bootstrap và trust boundary vẫn an toàn; nếu không chứng minh được, giữ blocker. Đã thêm giới hạn streaming checksum 1024 byte, archive và luồng tar giải nén 512 MiB, metadata latest 1 MiB và listing 100000 dòng; Test checksum HTTP chunked vượt ngưỡng và gzip bị cắt đạt; test chunked archive/latest và portability vẫn chưa hoàn tất. Đã thêm job macOS installer vào CI và gate publish release; job macOS của workflow 45009569543 đạt cho fixture installer trên macOS. Chưa kiểm tra artifact release thật trên macOS. Giới hạn listing chưa chứng minh đếm chính xác mọi định dạng tar; chưa đóng blocker.
2. [ ] **Configured suite:** `test all` chỉ chọn `infra` chạy thêm `gofmt`, `go vet` và coverage Go toàn bộ với ngưỡng tạm thời 80%; CI gọi chính gate này. Ngưỡng áp cho Go là kiểm tra bảo thủ mới, không chứng minh tương đương coverage Python cũ. Coverage Go đạt 80,0% (2688/3360 statement); lần chạy CLI thực tế hoàn tất các check infrastructure nhưng báo `partial`, exit 2, `full_regression=false` vì parity chưa xác minh. Đã xác minh timeout dừng tiến trình con nhưng không ảnh hưởng tiến trình ngoài trên Linux; thêm kiểm tra Compose chỉ truyền tên môi trường đã khai báo. `--pattern` ở Go test từng bị bỏ qua; nay từ chối rõ thay vì báo thành công sai. Chưa khôi phục lọc pattern hay xác minh tương đương logging/quiet của suite Python cũ. Khi các kiểm tra đạt, kết quả vẫn `partial`, `full_regression=false` cho tới khi chứng minh parity với regression Python đã xóa. Cần bổ sung test hành vi thiếu và hoàn thiện báo cáo; chưa release-ready. Source Go được mount read-only; flag infra chưa hỗ trợ bị từ chối.
3. [ ] **Transaction và cạnh tranh:** Thêm failure injection tại các bước stage, chuẩn bị binary, tạo link và activation cho installer lẫn updater; kiểm tra release hiện tại, project data, lock và cleanup. Đã test hai tiến trình thật: installer giữ lock tại download, updater bị từ chối; xác minh bản cũ, cấu hình project và cleanup lock sau lỗi download. Đã test thêm installer bị từ chối khi một tiến trình Go khác giữ cùng lock; chưa chứng minh chiều updater thật giữ lock trong lúc installer chạy. Ghi rõ hành vi phục hồi stale lock sau crash. Đã test lỗi `mv -Tf`, TERM ngay sau khi chuyển release vào thư mục version và TERM sau đổi symlink trên Linux. Sửa cleanup để không xóa release `current` đang tham chiếu và xóa release mồ côi trước activation. Đã xử lý TERM giữa tạo lock và xác nhận sở hữu bằng cách hoãn signal tới khi biết kết quả `mkdir`; regression test giữ lock của tiến trình khác và dọn lock của mình. Review độc lập lock/signal không tìm thêm lỗi tin cậy; SIGKILL hoặc crash vẫn có thể để stale lock, các bước và nền tảng khác chưa được bao phủ. Artifact build thành công sau sửa lock; cài từ local mirror, checksum, version và init đạt trên Linux. Fixture installer trên macOS đã đạt CI; chưa chạy acceptance artifact thật trên macOS hoặc kiểm thử toàn bộ rollback.
4. [ ] **Migration và rollback:** Đã sửa README về PATH thủ công, backup, init, skills lock và kiểm tra stale lock; chưa có hướng dẫn rollback global từng bước đã nghiệm thu. Cần xác minh migration, rollback và tương thích dữ liệu với release cũ thực tế.
5. [ ] **Compatibility và release metadata:** Xác minh đường chuyển đổi từ release cũ thực tế, consumers trong phạm vi và CI; ghi breaking change, known limitations, checksum/provenance và hướng dẫn khôi phục. Không giả định đã migrate repo bên ngoài hoặc Rust target hoạt động.
6. [ ] **Verification cuối:** Sau mọi thay đổi, chạy Go suite, installer tests và `leedevkit test all --json`; build artifact mới bằng `scripts/build-release-go.sh` tại thư mục output mới. Kiểm tra manifest, SBOM, checksum, cài local mirror, chạy offline, update từ binary release cũ thực tế, lỗi update và rollback trong môi trường cô lập. Chạy acceptance trên Linux và macOS cho platform còn được công bố hỗ trợ; nếu không có môi trường, ghi blocked và không kết luận release-ready. Thực hiện security review độc lập và `git diff --check`; lưu kết quả pass/fail/blocked.

## Điều kiện hoàn tất

Các gate trên đạt, không còn blocker bảo mật hoặc mất dữ liệu, CI và consumers trong phạm vi có đường chuyển đổi đã xác minh. Phát hiện mới phải được sửa và kiểm thử lại trước khi kết luận; phát hành thực tế cần yêu cầu riêng.
